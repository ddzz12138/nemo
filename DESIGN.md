## Truthfulness and release

Examples are fictional. Shared-calendar outing planning is explicitly future work, with each person's choice to share; current calendars are private. Child mode illustrates a future family experience with guided learning and visible parent review, without promising to prevent every workaround. Public child access is not open in the current preview. Personal responses require personal context; Calendar and Gmail are optional connections with their own setup.

Nemo is independent and built on Nous Research's Hermes. Hermes has its own interfaces, memory and skills. Nemo adds guided setup, family data and controls with scoped family reads; the local owner's workspace exposes Hermes's native tools and approvals on the home PC. Native Hermes memory saves useful notes automatically in each person's private store. Relevant saved notes, conversation context and permitted tool results go to ChatGPT for replies. GBrain extraction/embeddings and local AI models remain deferred.

The Windows app source is public and remains a development preview. Public downloads and hosted phone access are being prepared. The illustrated setup requires an eligible ChatGPT plan; plan limits and credit settings apply. Do not imply all-local inference, automatic account connections, guaranteed setup times, finished hardware or a release date.
