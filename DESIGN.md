Two seconds into that rest, the headline cycles everyone → Mum → Dad → Children → everyone; it finishes before the next conversation starts. There are no replay or skip controls. One viewed-time clock pauses both sequences when less than a quarter of the phone panel is visible or the document is hidden, then resumes without catching up. The complete static conversation and heading remain available with reduced motion, missing APIs or a rendering failure. A stalled renderer settles to the static view. The glass capsule stays fixed over the page while its header preserves the original layout space. Scrolling down one capsule height hides it; scrolling up eight pixels reveals it. It stays visible near the top and returns immediately on keyboard focus. The translucent fill and backdrop blur let content remain visible underneath. This behavior is shared by all three pages, with no scroll hijacking and no animated transition for reduced motion.

## Truthfulness and release

Examples are fictional. Shared-calendar outing planning is explicitly future work, with each person's choice to share; current calendars are private. Child mode supports guided learning and visible parent review, without promising to prevent every workaround. Personal responses require personal context; memory and connections need their own setup.

Nemo is independent and built on Nous Research's Hermes. Hermes has its own interfaces, memory and Skills. Nemo adds guided setup, family data and controls with selected read tools. Nemo's personal GBrain memory is separate from shared Hermes context injection. Connected AI providers receive context and permitted tool results needed to answer.

The Windows app remains a development preview. Public downloads and hosted phone access are being prepared. The illustrated setup uses an eligible ChatGPT plan; plan limits and credit settings apply. No all-local model, automatic connections, guaranteed setup times or release date claims.

GitHub Pages publishes the verified docs/ artifact from main through the website workflow. Prepare Ranade during deployment and retain its licence/provenance notice, rather than redistributing font binaries in the public repository. No runtime font-provider requests or npm dependencies are needed. VERSION and CHANGELOG track this website only.
