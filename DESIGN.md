# Nemo public website

## Direction

Three concise pages separate vision, setup and foundations. Home keeps the original centred editorial composition, then shows family outing planning, Child mode, personal responses and a routine improved through remembered feedback. How it works preserves the approved setup sequence. About Nemo shows the same Hermes engine inside and outside Nemo's family experience.

The memory example follows school emails: first request → “Only actions. Deadlines first. Remember that.” → a later deadline-first checklist. This is an on-demand example with configured Gmail and memory, not automatic background work or Hermes Skills exposed through Nemo.

## Visual language

Orange #F26A2E, dark orange #AD3C16, ink #26211E, warm white #FFF9F5, peach panels and restrained borders. Georgia editorial headings, system sans body and interface text. Original inline SVG illustrations; no family photography, handset mockups, external fonts or runtime dependencies.

Main and conversational text is at least 16px. Critical preview, future-feature and consent labels are at least 14px. Use dark text on orange and white text only on dark orange. Content width 1120px and compact sections scale down to 20px phone gutters. No empty viewport-sized chapters, scroll hijacking or hidden-until-revealed copy.

## Interaction and access

All pages, normal links and native disclosures work without JavaScript. The optional script only routes legacy Home bookmarks. Retain #everyday, #family, #memory and #start targets. Setup controls are static illustrations with no interactive roles. Text equivalents explain the calendar, engine relationship and routine; decorative SVGs are hidden from assistive technology.

Check keyboard focus, skip links, disclosures, browser history and layouts from 320px through desktop. Respect reduced motion and retain relative asset paths for /nemo/.

## Truthfulness and release

Examples are fictional. Shared-calendar outing planning is explicitly future work, with each person's choice to share; current calendars are private. Child mode supports guided learning and visible parent review, without promising to prevent every workaround. Personal responses require personal context; memory and connections need their own setup.

Nemo is independent and built on Nous Research's Hermes. Hermes has its own interfaces, memory and Skills. Nemo adds guided setup, family data and controls with selected read tools. Nemo's personal GBrain memory is separate from shared Hermes context injection. Connected AI providers receive context and permitted tool results needed to answer.

The Windows app remains a development preview. Public downloads and hosted phone access are being prepared. The illustrated setup uses an eligible ChatGPT plan; plan limits and credit settings apply. No all-local model, automatic connections, guaranteed setup times or release date claims.

GitHub Pages publishes docs/ from main. VERSION and CHANGELOG track this website only. Never publish private app data or change the legacy Sites redirect checkout in a website update.
