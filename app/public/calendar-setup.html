YOUR SPACE, CONNECTED

Your week.
Within reach.

Build an Apple Shortcut to upload a snapshot of selected calendar events for the next seven days to your PC.

This is a manual setup guide, awaiting verification on your iPhone. Nemo cannot silently install a Shortcut or read your phone’s calendar from Safari. The steps use Apple’s documented Dictionary and JSON request features, but the exact nested-list editor and the complete upload have not been tested on your device. No installable Shortcut is included.

1. Create a token from your phone’s HTTPS address

First finish phone access in Nemo on your computer. On your iPhone, open Nemo at its HTTPS address, pair the phone, then open menu → Connected accounts → Calendar → Create sync token. This supplies the phone endpoint directly. When you create a token on the PC, Nemo uses its saved private HTTPS address; if that address is not configured, it shows a setup notice instead of a loopback endpoint.

Copy the displayed endpoint and token into your private Shortcut. An endpoint ends in /api/calendar/import. Do not substitute localhost or 127.0.0.1: on the iPhone those refer to the phone itself. Use Authorization: Bearer YOUR_TOKEN as the request header; never add it to the URL. The token expires after 30 days; replacing it revokes the previous token.

2. Build “Nemo Sync Calendar”

In Apple’s Shortcuts app, create a shortcut with that exact name. The names below describe the intended actions and values; controls can vary with iOS version and language. Use the variable picker to select action outputs, rather than typing variable names as ordinary text. Apple’s variable instructions

  1. Define the window. Take Current Date and save it as Window Start. Use Adjust Date to add seven days to that date and save it as Window End. Format each with Format Date using ISO 8601; save the text outputs as Range Start and Range End. The dates must include a time-zone offset or Z. Apple’s timestamp guidance
  2. Find the events. Add Find Calendar Events, limited to calendars you choose and events whose start date falls between the two window dates. Sort by start date, earliest first; limit to 200. This initial filter finds events starting in the window, so it can miss an event that started earlier and is still running.
  3. Make an event dictionary per result. Use Repeat with Each on the found events. Within the loop, get the current Repeat Item’s title, start date, and end date. Format both event dates as ISO 8601. Make the final action inside the loop a Dictionary with three Text values: title = that event’s title; start = its formatted start; end = its formatted end. The loop’s Repeat Results should be a list of these dictionaries, one per event. Save it as Events. Apple’s Repeat Results guidance
  4. Build the payload as a Dictionary. Create top-level keys events, rangeStart, and rangeEnd. The events value must be the entire Events list, preserving each item as a dictionary. The other two values are the formatted range text variables. Save this dictionary as Payload. For zero found events, explicitly use an empty Array for events. Optional: add Text timeZone with an IANA name such as Australia/Sydney. Apple’s typed dictionary values
  5. Preview before uploading. Add Quick Look with Payload selected as its input. Check that events contains dictionaries, not event objects, a text string, or a second list wrapped around your list. For a first run, use one harmless test appointment on a calendar you chose. Quick Look can also preview Events immediately after the loop. Apple’s action testing guidance
  6. Configure the JSON request. Add a URL action with the exact private HTTPS endpoint copied from Nemo. Add Get Contents of URL, expand its options, set Method to POST, and set Request Body to JSON. Set headers Content-Type = application/json and Authorization = Bearer YOUR_TOKEN, with one space after Bearer. Replace YOUR_TOKEN with the actual token. Supply Payload as the body dictionary through the variable selector if your editor offers it. If it instead shows editable body rows, enter the same top-level keys there using the same typed values and variables. Do not add a wrapper key named Payload. Apple’s JSON request-body guidance
  7. Inspect the response. Add Quick Look after the request, with the request’s response selected. Run manually and approve the calendar and network access you intend to grant. A successful upload returns "ok": true. Return to Nemo → menu → Connected accounts → Refresh status and verify its last-sync time and event count.

If the date formatter offers a custom pattern, use yyyy-MM-dd'T'HH:mm:ssXXX for the required seconds and colon time-zone offset.

Device checkpoint: Apple documents JSON request bodies and typed dictionaries, but not every iOS version’s nested-array picker. If your editor will not accept the whole Events list as the array value, stop before uploading and verify that control on the phone. Do not change it to a Text value, wrap the list in another array item, or assume an untested File conversion will preserve the payload.
Expected body and troubleshooting

This is the JSON shape the request must send. The dates are illustrative only; the Shortcut must generate current dates each run.

{
  "events": [
    {
      "title": "Example appointment",
      "start": "2026-10-21T14:00:00+11:00",
      "end": "2026-10-21T14:30:00+11:00"
    }
  ],
  "rangeStart": "2026-10-21T08:00:00+11:00",
  "rangeEnd": "2026-10-28T08:00:00+11:00",
  "timeZone": "Australia/Sydney"
}

An empty window needs "events": [], with both current range fields still present. Optional per-event allDay must be a Boolean if included. Omit notes, attendees, locations, and attachments.

  • “events array”: check the array type and dictionary items; do not send the list as text or nest the whole list as one array element.
  • “valid JSON”: check Request Body is JSON and the top-level body is the dictionary shown above. Use typed values rather than hand-building JSON text from appointment titles.
  • Unauthorized: check the private token, its expiry, and the Bearer header. A replacement token requires updating the Shortcut.
  • Cannot connect: keep Nemo running on the computer and check that phone access is ready; confirm the exact HTTPS address opens in Safari over cellular.

Each successful upload replaces the previous snapshot, so removed events disappear. An empty upload clears the events in that snapshot. Disconnecting Calendar deletes the snapshot and revokes its token. Do not put the token in chat, URLs, or screenshots.

3. Ask about your day

Open Connected accounts from Nemo’s menu and enable Allow Nemo to use connected tools and ask “What does my day look like?” This preference stays on for later questions until you switch it off. While enabled, selected calendar information and Gmail summaries are added to new questions sent through your existing Hermes cloud AI. Switching it off or disconnecting does not erase information already sent or existing chat history.

Keep it up to date

First verify a manual upload on the iPhone over cellular, including an empty calendar and the expected time zone. This is not a continuous calendar sync service. Then consider a Time of Day personal automation. Locked-phone execution, permissions, background timing, and the phone connection still require testing on your device. Until then, refresh by running the Shortcut manually.

This token uploads only to your personal profile. Each family member creates their own token and Shortcut. Your paired devices can use your synced calendar when you allow connected tools in Settings.
