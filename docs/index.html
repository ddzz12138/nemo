A FEW THINGS YOU MIGHT WONDER

Before you
come on in.

Can I install Nemo today?+

Public app downloads are not available yet. Nemo is in private family testing. We are preparing a small, invited Windows alpha, with public source and installation instructions to accompany the first release. Follow the GitHub repository for updates; there is no launch date yet.

Is Nemo free?+

Nemo is being built as free, open-source software under the MIT license. The public source and first installable alpha are being prepared. You will provide the computer and a compatible Hermes setup; your chosen AI provider may charge for model usage.

Does it all run locally?+

The Nemo server, profiles, and stored data live on your computer. Local GBrain handles memory. Chat replies use the model provider configured in Hermes; if that is a cloud provider, the conversation and relevant context go to that provider. Local hosting alone doesn’t make every AI request local.

Do family members share one chat?+

No. Each person has their own profile, chat history, memory, and connected accounts. An additional device can resume the same person’s profile. Owners manage invitations and devices.

How does child mode work?+

Child mode encourages explanations and hints instead of simply completing homework. Parents control available tools and can review child conversations and memory; that review is visible to the child. It’s an early feature that will improve over time.

Can I use Nemo away from home?+

Yes, with your private HTTPS connection, such as Tailscale. Your phone and host computer need access to that connection, and the host must stay awake and online. The public project website never gives access to your private Nemo server.

Can I help build it?+

Absolutely. Start with the GitHub repository. Share an idea, report a bug, or propose a contribution. Nemo is early, and thoughtful feedback helps it grow.
