How do the pieces fit together? +

Nemo identifies the signed-in person and supplies their allowed context and connections to Hermes. Hermes manages the conversation and permitted tool calls, using the connected model to produce replies. Nemo presents the answer and tool activity.

Whose memory does Nemo use? +

Nemo manages per-person GBrain memories. Shared Hermes memory/context injection is disabled in the family integration. History and memories are separate from calendar and email caches.

Is Nemo made by Nous Research? +

Nemo is an independent project built on the open-source Hermes Agent, created by Nous Research. Hermes deserves credit for the agent underneath Nemo.

What is still being built? +

Public desktop distribution, the hosted phone connection and advanced tool execution still have rollout work. Shared family-calendar planning is a future vision. Calendar, Gmail and memory each retain their own setup requirements.

Independent. Open source. Built on good foundations.
